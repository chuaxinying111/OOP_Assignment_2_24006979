## 1. Project Title
Sea Shark 

## 2. Project Description
This project is a console-based implementation of a game-based learning system.  
It demonstrates basic Object-Oriented Programming (OOP) concepts in C# which focus on encapsulation.

This game allows users to answer quiz questions and progress through different levels.

---

## 3. Features
- Level selection (Beginner and Advanced)
- Quiz system with multiple choice questions
- Key collection system
- Level unlocking mechanism
- Timer for each level
- Simple console interaction

---

## 4. OOP Concepts Used
- Encapsulation (private fields and public properties)
- Constructors
- Object interaction
- Method invocation
- Inheritance (GameLevel, BeginnerLevel, AdvancedLevel)
- Abstraction (using abstract class GameLevel to define common structure for levels)

---

## 5. Classes Implemented
- GameManager
- Player
- GameLevel (abstract)
- BeginnerLevel
- AdvancedLevel
- Quiz
- Timer

---

## 6. How to Run the Program
1. Open the project in Visual Studio  
2. Build the solution  
3. Run the program  
4. The output will appear in the console  

---

## 7. GitHub Structure Explanation
- Program.cs : Contains the Main method  
- GameManager.cs : Controls the game flow  
- Player.cs : Handles player actions and data  
- GameLevel.cs : Abstract class for levels  
- BeginnerLevel.cs : Implement Beginner level  
- AdvancedLevel.cs : Implement Advanced level  
- Quiz.cs : Handles quiz questions and answers  
- Timer.cs : Manages time for each level
